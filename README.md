# FRAME — портфолио видеокреатора

Авторский чёрно-серебряный сайт: 3/2/1 колонки, inline video, отдельный адрес /contacts, CSS motion, reduced motion и остановка непрерывного движения. Рабочий деморежим не требует аккаунтов.

## Что менять

Текущие шесть роликов SMOLIN.FX скачаны из Instagram и размещены в `public/media/*.mp4`. Поле `src` в `content/portfolio.json` подключает их к встроенному плееру; `url` сохраняет ссылку на оригинал. При наличии `src` просмотр открывается внутри сайта. Видео публикуются вместе с проектом; отдельный аккаунт видеохостинга для этой версии не нужен.

До подключения админки текущие данные берутся из `content/portfolio.json`: имя, описание, email, соцсети, works и logos. Пустой email не превращается в вымышленный адрес.

- Работа: `id` (уникальный), `title`/`titleRu`, `client`, `kind`/`kindRu`, `order`, `poster`, `muxPlaybackId` **или** `src` (MP4/HLS), либо внешняя `url` (например Instagram Reel), `previewStart`, `duration`, `demo`, необязательно `captions` (WebVTT).
- Спонсор: `name`, `image`, `url` (HTTPS), `order`. PNG лучше загружать с прозрачным фоном.
- Контакты: `email`, `phone`, `socials: [{name, url}]`. Instagram определяется по названию или адресу `instagram.com`; `name` верхнего уровня — имя или авторский логотип. Английский интерфейс открывается первым, выбор русского сохраняется в браузере.

Изменение JSON требует повторной публикации сайта. Для обновления через кнопку Publish без изменения кода предусмотрено подключение Sanity ниже.

## Рабочий процесс после подключения

1. В **Sanity Studio → Портфолио → Работы** добавьте запись и выберите видеофайл. Он загрузится в Mux прямо из админки.
2. Заполните название, клиента, тип, длительность и порядок. Постер можно загрузить вручную; без него сайт запросит кадр у Mux.
3. Нажмите **Publish** в Sanity. При следующем открытии/обновлении страницы работа будет в сетке. Пересборка сайта не нужна.
4. Логотипы, контакты и имя редактируются в том же документе.

Сайт получает только опубликованный документ. Черновики Sanity не показываются. Не создавайте несколько документов типа «Портфолио» — предусмотрен один. При недоступности подключённой CMS сайт честно показывает ошибку с повторной загрузкой, а не подменяет ваши работы демоматериалами.

## Однократное подключение владельцем

Пока **Mux и Sanity не подключены**, сайт продолжает использовать локальные данные и видео. Готовая Studio, Mux-загрузка, HLS-плеер и серверное чтение Sanity уже добавлены.

1. Создайте аккаунты Mux и Sanity. Для публичного портфолио достаточно Public playback и public dataset. Не храните в публичном dataset приватные сведения.
2. Подключите готовую Studio из папки `studio/` по инструкции ниже.
3. Создайте один документ «Портфолио», заполните обязательные для показа материалы, опубликуйте. Не оставляйте пустые названия, повторяющиеся порядки и работу без Playback ID/ссылки. `_key` элементов Sanity используется как стабильный id.
4. Добавьте серверные переменные `SANITY_PROJECT_ID` и `SANITY_DATASET=production` в Vercel → Project Settings → Environment Variables; локально — в `.env` (не коммитится). Затем выполните один новый деплой.
5. После этого все последующие изменения контента публикуются из Studio. CMS-запрос идёт с сервера, поэтому браузерный CORS для сайта не нужен. Токены записи в браузере отсутствуют; редакторов и вход в Studio контролирует Sanity.

## Админ-панель Sanity + Mux

Готовая Sanity Studio лежит в `studio/`. В ней одна запись «Портфолио»: работы с прямой загрузкой видео в Mux и спонсоры с PNG-логотипом, HTTPS-ссылкой и порядком. После Publish сайт читает обновления без изменения кода. Логотипы автоматически становятся одноцветными; при наведении светлеют, а клик открывает сайт спонсора.

Подключение аккаунтов:

1. Создайте проекты в Sanity и Mux. Для библиотеки больше 10 видео в Mux нужен Pay as you go; отдельный фиксированный тариф Vimeo не требуется.
2. Скопируйте `studio/env.example` в `studio/.env` и вставьте Project ID из Sanity. Секреты Mux в файл не добавляйте.
3. Выполните `cd studio && npm run dev`, войдите в Sanity и откройте первое поле загрузки видео. Плагин один раз попросит Mux Access Token и Secret с правами чтения и записи видео.
4. Создайте один документ «Портфолио» и нажмите Publish. Для сайта добавьте `SANITY_PROJECT_ID` и `SANITY_DATASET=production` в Vercel и сделайте один redeploy.
5. Админку можно опубликовать отдельной командой `cd studio && npm run deploy`; дальнейшие видео, постеры и спонсоры добавляются через неё.

Mux обрабатывает исходник в адаптивный поток для разных устройств. В Studio разрешены видео до 30 GB и до 4K; режим Basic выбран для более экономного хранения и доставки.

Если нужны private/signed видео, эту конфигурацию надо расширить серверной выдачей подписей. В текущей реализации используются публичные портфолио-работы.

## Видео и загрузка

`preload=none`; до взаимодействия у video нет src. Только один main player и не более одного muted hover-preview. При запуске main все остальные видео останавливаются. На touch hover не используется. Полный кадр во время просмотра (`object-fit: contain`), включая вертикальные исходники. Управление — нативное: пауза, звук, перемотка, fullscreen (на iPhone — системный плеер). Превью выключены при reduced motion, Save-Data и ручной остановке движения. HLS.js подгружается только для HLS, если нет нативного HLS. Скрытая вкладка останавливает видео.

## Разработка

`npm install`, `npm run dev`, `npm run build`. Среда Next.js / React, подготовленная для Vercel. Один CSS motion vocabulary, без перехвата скролла и WebGL. Нативный HTML video сохраняет системное управление и клавиатуру.

## Публикация на Vercel

Подключите репозиторий к Vercel и используйте корень репозитория. Framework Preset должен быть `Next.js`, Build Command — `npm run build`, Output Directory — без ручного значения. Файл `vercel.json` фиксирует Next.js как фреймворк. Production-сборка использует официальный Webpack-режим Next.js для предсказуемой совместимости. После изменения этих настроек нажмите Redeploy для последнего коммита.

Сравнение видеопровайдеров и расчёты: `VIDEO-HOSTING.md`. Проверки и ограничения: `VALIDATION.md`.
